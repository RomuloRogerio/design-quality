Skills
Three skills, one repo.
design-quality
Review any UI for AI slop patterns, score 8 quality dimensions (1–10), and run 10 ordered fix passes from spacing to motion.
Review Create Fix Polish
ant-design
Audit React UIs against Ant Design v6: color tokens, 4px grid, component archetypes, motion durations, and elevation rules.
Tokens Components 4px grid
system-design
Plan scalable architectures: 5-step design framework, DB and cache selection, CAP trade-offs, rate limiting, and non-functional requirements.
Architecture CAP Caching
all
Loads all three. Claude picks the right skill based on context: UI work activates design-quality or ant-design, architecture work activates system-design.
Meta-skill Context-aware
Plugin
Slash commands for any session.
/dq-review
Full audit: slop detection, 8-dimension scorecard, P0–P3 fix list.
/direction
Derives product direction before writing any UI code. Character, World, Moments, Signature.
/fix
10 sequential passes: Spacing → Color → Icons → Copy → Typography → Layout → Details → A11y → Visuals → Motion.
/polish
Walks every state at 10% speed: hover, focus, active, loading, empty, error.
# clone and run with the plugin git clone https://github.com/RomuloRogerio/design-quality claude --plugin-dir ~/design-quality/plugin # or add to ~/.claude/settings.json to load always { "pluginDirs": ["~/design-quality/plugin"] }
